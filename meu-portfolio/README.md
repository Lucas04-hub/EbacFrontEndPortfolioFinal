## 🚀 Como rodar localmente

1. Clone este repositório:
git clone https://github.com/SEU_USUARIO/seu-repo-portfolio.git

2. Instale as dependências:
npm install

3. Rode o projeto:
npm start

O site abrirá em: http://localhost:3000
